

> **버전**: 0.1 (초기 기획안) **장르**: Cozy 운영 시뮬레이션 + 캐주얼 미니게임 **플랫폼**: 웹 (모바일/데스크탑) **목표 플레이타임**: 한 영업일 약 2~5분, 누적 플레이는 자유

## 1. 게임 개요

### 1.1 한 줄 소개

cozy한 햄버거 가게를 운영하며, 손님의 주문을 두 가지 미니게임(기억력/스피드)으로 응대하고, 모은 돈으로 가게를 꾸며나가는 캐주얼 게임.

### 1.2 핵심 컨셉

- **짧고 가벼운 한 판**: 한 영업일이 2~5분 내외로 끝나 부담 없이 즐길 수 있다.
- **두 미니게임의 조합**: 단조로움을 피하기 위해 성격이 다른 두 게임을 한 가게 안에서 번갈아 등장시킨다.
- **메타 진행도**: 미니게임 자체의 재미 위에 "가게를 키워가는" 장기 목표를 얹어, "한 번 더" 동기를 강화한다.
- **플레이어가 페이스를 통제**: 난이도와 영업 여부 모두 플레이어가 선택. cozy 톤을 유지한다.

### 1.3 타겟 유저

- 출퇴근, 짧은 휴식 시간에 가볍게 즐길 거리를 찾는 캐주얼 게이머
- Cooking Mama, Good Pizza Great Pizza, Stardew Valley 류의 cozy 게임을 즐기는 유저
- 짧은 호흡의 미니게임에서 즉각적 만족을 얻고 싶은 유저

### 1.4 레퍼런스

- **Cooking Mama**: 단순한 미니게임의 반복 + 만족스러운 피드백
- **Good Pizza Great Pizza**: 손님 응대 루프 + 가게 운영의 cozy함
- **사이먼 세이즈**: 기억력 미니게임의 정석적 룰
- **Overcooked**: 시간 압박 속 주문 처리의 쾌감(스피드 게임 참고)

	│

	│
	├─ 점심 시간대 (4~6명)

	│

[매출 정산 화면]
	│
	│ 레벨업 체크
	│ 꾸밈요소 해금 체크
	│
	▼

### 2.2 손님 응대 단위 흐름

```
손님 등장
	│
	├─ 미니게임 종류 결정 (시간대별 비율 따름)

	▼

```

## 3. 미니게임 상세

### 3.1 기억력 게임

#### 룰

- 햄버거 레시피를 일정 시간 동안 보여준 뒤 가린다.
- 플레이어는 외운 순서대로 재료를 클릭해 쌓아 햄버거를 완성한다.
- 기회 3번. 틀린 재료를 클릭하면 기회 -1.
- 기회를 모두 소진하면 실패.

#### 화면 구성

- **레시피 영역**: 게임 시작 시 주문 레시피의 재료를 순서대로 표시
- **상단**: 남은 기회 표시 (하트 3개 또는 동일 컨셉)
- **중앙**: 빈 접시 → 재료가 쌓여가는 영역
- **하단**: 재료 선택 버튼 슬롯

#### 진행 단계

1. **레시피 표시 단계**: n초 동안 레시피 재료를 순서대로 보여줌
	- 표시 시간 = `기본 시간 + 재료 수 × α`
	- 플레이어가 "준비완료" 버튼을 누르면 즉시 다음 단계로
2. **레시피 가림**: 레시피 영역이 가려지고, 재료 선택 슬롯이 활성화됨
3. **재료 선택 단계**: 플레이어가 순서대로 재료 클릭
	- 정답: 접시에 "철퍽" 효과음과 함께 재료 쌓임
	- 오답: 재료가 쌓이지 않고 짧은 진동/빨간 플래시, 기회 -1
4. **완성 단계**: 빵빠레 이펙트 + 후광 효과 → 아무곳 클릭 시 가게 화면 복귀

### 3.2 스피드 게임

#### 룰

- 제한 시간 내에 여러 햄버거 주문을 모두 처리한다.
- 시작 시간 30초(예시), 햄버거 1개 완성 시마다 보너스 시간(+5초 예시) 추가.
- 각 햄버거는 완성 모습으로 화면에 표시되며, 플레이어는 동일하게 재료를 쌓아야 한다.
- 시간 안에 모든 주문을 처리하면 성공, 시간 초과 시 실패.

#### 화면 구성

- **상단**: 남은 시간 (게이지 + 숫자)
- **상단 그 아래**: 처리할 햄버거 행렬 - 현재 햄버거를 크게, 뒤이은 주문들은 옅고 작게
- **중앙**: 빈 접시
- **하단**: 재료 선택 버튼 슬롯

#### 진행 단계

1. **카운트다운**: 3-2-1 후 게임 시작
2. **주문 처리 단계**:
	- 햄버거 완성 시 → 옆으로 슬라이드, 새 빈 접시 등장, 보너스 시간 추가
	- 틀린 재료 클릭 시 → 쌓이지 않음, 짧은 페널티 피드백
3. **완료 단계**: 모든 주문 처리 → 빵빠레 이펙트 + 후광 → 아무곳 클릭 시 가게 화면 복귀

#### 스피드 게임의 틀린 재료 처리

- 기억력 게임과 동일하게 안 쌓임 + 짧은 피드백
- 별도의 "기회" 개념은 없음 (시간 페널티로 자연스럽게 압박)
- 단, 틀린 재료 클릭 시 짧은 시간 페널티(-1초 등)를 추가해 신중함을 유도할지 추후 결정

## 4. 시간대 시스템

### 4.1 시간대 구성

한 영업일은 세 개의 시간대로 나뉜다.

|시간대|손님 수|기억력 비율|스피드 비율|분위기|
|---|---|---|---|---|
|아침|2명|70%|30%|차분한 워밍업|
|점심|4~6명|30%|70%|러시아워, 긴장감|
|저녁|2명|50%|50%|균형, 마무리|

### 4.2 의도

- 같은 영업일 안에서도 무드의 변화가 있어 단조로움 방지
- "점심 러시 잘 버텼다"는 자연스러운 성취감
- cozy + 운영 시뮬의 리듬

### 4.3 시간대 전환 연출

- 시간대 전환 시 짧은 컷씬 또는 화면 톤 변화 (아침: 밝은 빛 / 점심: 활기 / 저녁: 따뜻한 노을)
- 시간대 시작 시 "아침 영업 시작" 같은 짧은 안내

## 5. 난이도 시스템

### 5.1 난이도 4단계

플레이어가 영업 시작 전 난이도를 선택한다. 난이도가 높을수록 보상이 커진다.

|난이도|등장 재료|재료 슬롯 표시|손님당 기본 보상|해금 조건|
|---|---|---|---|---|
|쉬움|4종|등장 재료 4종만|$1|처음부터|
|보통|6종|7~8종 (함정 포함)|$2|레벨 5|
|어려움|7종|8종 (함정 포함)|$4|레벨 10|
|전문가|8종|8종 + 추가 함정|$7|레벨 15|

> 보상 수치는 초기값 예시. 플레이테스트로 조정 필요.

### 5.2 슬롯 표시 정책

- **쉬움**: 슬롯에 등장 재료만 표시 → 순수 기억력 시험
- **보통+**: 등장하지 않는 재료(함정)도 슬롯에 표시 → 기억력 + 판단력 시험
- 함정 재료는 미세하게 흐리게 표시하여 "현재 등장 가능한 재료"는 은은하게 식별 가능
	- 너무 강한 시각 차이는 함정 효과를 희석시키므로 절제
	- (이 부분은 플레이테스트로 강도 조정 필요)

### 5.3 새 재료 해금 시 처리

- 5레벨 단위로 새 재료가 게임에 추가됨
- 새 재료가 해금된 이후, **모든 난이도의 게임에 적용**
- 새 재료 첫 등장 시: 슬롯에 "NEW" 뱃지 또는 짧은 반짝임 효과 (1~2초)
- 첫 등장 손님은 해당 재료를 반드시 사용하는 레시피로 등장 (선택사항, 추후 결정)

## 6. 진행 시스템

### 6.1 돈과 레벨

- 손님 응대 성공 시: 난이도별 기본 보상 획득
- 손님 응대 실패 시: 최소 보상(기본 보상의 약 10%) 획득 — 진행 정체 방지
- 누적 돈에 따라 레벨업 → 가게 꾸밈 요소 해금
- 5레벨 단위(레벨 5, 10, 15, 20)에 새 난이도 + 새 재료 해금

### 6.2 레벨업 곡선 (초기안)

|레벨|누적 필요 돈 (예시)|비고|
|---|---|---|
|1→2|$5|첫 영업일 ~2~3회|
|2→3|$12||
|3→4|$25||
|4→5|$45|보통 난이도 해금|
|5→6|$75||
|...|(점진 증가)||
|9→10|~$300|어려움 난이도 해금|
|14→15|~$1000|전문가 난이도 해금|

> 곡선은 플레이테스트로 정밀 조정. 후반에는 1회 영업일로는 다음 레벨 도달이 어려운 정도로 설계.

### 6.3 가게 꾸밈 요소

- 레벨업 시 새로운 꾸밈 요소가 해금됨 (간판, 화분, 액자, 카운터 장식 등)
- **위치는 자동, 배치 여부는 플레이어 선택**
	- 해금된 요소를 가게 화면에서 "배치" 또는 "치우기" 토글
	- 위치는 게임이 자동으로 정해, UX 부담 최소화
- 꾸밈은 게임플레이에 영향을 주지 않는 순수 시각 보상

## 7. 안전장치 / UX 디테일

### 7.1 첫 플레이 경험 (튜토리얼)

- **첫 손님**: 강제로 기억력 게임, 재료 2개짜리 짧은 레시피, 표시 시간 길게
- **두 번째 손님**: 강제로 스피드 게임, 햄버거 1개짜리, 시간 여유롭게
- **세 번째 손님부터**: 정상 흐름
- 튜토리얼은 첫 영업일에만 등장
- 별도의 텍스트 가이드는 최소화하고, 직접 해보면서 익히도록 유도

### 7.2 실패 시 보상

- 실패해도 최소 보상($0.1~$0.7 수준)을 받아 누적 돈이 0으로 머물지 않음
- 메시지: "수업료" 같은 따뜻한 톤
	- 예: "괜찮아요, 다음에 더 잘하면 돼요" 같은 짧은 멘트

### 7.3 매출 정산 화면

영업 마감 시 표시되는 정보:

- 처리한 손님 수 / 놓친 손님 수
- 시간대별 매출(아침/점심/저녁)
- 오늘의 총 매출
- 레벨업 발생 여부
- 다음 레벨까지 필요한 금액 (게이지)
- (선택) 오늘의 베스트 메뉴, 오늘의 콤보 등 작은 재미 요소

이 화면은 cozy 게임의 핵심 보상 순간이므로 짧지만 만족감 있게 연출.

### 7.4 영업 도중 중단

- 영업 종료 버튼은 영업 중 언제든 누를 수 있음
- 도중 종료 시 그때까지의 매출로 정산
- "쉬어가도 괜찮아요" 톤 유지

## 8. UI / UX 화면 구성

### 8.1 가게 화면 (메인)

- 게임 실행 시 처음 보이는 화면

	- **영업개시** (큰 버튼, 메인 액션)

	- **난이도 선택** (영업 시작 전)
	- **꾸밈 요소 토글** (서랍 메뉴 또는 별도 화면)
	- **현재 돈 / 레벨 표시** (상단 정보 바)

### 8.2 미니게임 화면

7.3 참조.

## 9. 비주얼 / 사운드 톤

### 9.1 아트 디렉션

- **Cozy, 따뜻한 색감**: 베이지/나무톤/우드톤 가게 인테리어
- **둥근 형태**: 모든 UI 요소와 캐릭터, 재료가 둥글둥글
- **단순하고 친근한 일러스트**: 디테일은 적게, 표정과 동작은 풍부하게
- **다크모드 대응**: cozy 톤을 유지한 어두운 모드 (저녁/밤 분위기)

### 9.2 사운드 디렉션

- **재료 쌓는 소리**: 재료별로 다른 효과음 ("철퍽" - 패티, "사각" - 양상추 등)
- **정답 피드백**: 짧고 경쾌한 멜로디 음
- **오답 피드백**: 부드럽지만 명확한 페널티 사운드 (가혹하지 않게)
- **완성 빵빠레**: 만족스러운 짧은 멜로디
- **BGM**: 잔잔한 cafe 풍 루프, 시간대별 분위기 변주

## 10. 개발 범위 (MVP & 확장)

### 10.1 MVP (1차 출시 목표)

**필수 기능**

- 가게 화면 (배경 1종)
- 미니게임 2종 완전 작동
- 난이도 1~2 (재료 4종, 6종)
- 영업일 시스템 (시간대 3구간, 손님 수 2/4/2)
- 매출 정산 화면
- 레벨 1~10
- 가게 꾸밈 요소 5~7종
- 첫 플레이 튜토리얼
- 사운드 기본 (재료/정답/오답/완성)
- 손님 외형 1~2종

### 10.2 2차 확장

- 난이도 3~4 + 추가 재료
- 손님 외형 다양화 (3~5종)

## 12. 결정 사항 변경 이력

- **v0.1 (초기)**:
	- 두 미니게임 합체 + cozy 가게 운영 메타로 컨셉 확장 결정
	- 난이도는 플레이어 선택, 보상 비례
	- 영업일은 시간대 3구간 + 손님 수 차등(A안) + 시간대별 게임 비율 차등(B안) 조합
	- 기억력 게임 기회 3번, 틀린 재료 안 쌓임
	- 스피드 게임 시작 시간 + 완성당 보너스 시간 방식
	- 실패 시 최소 보상 적용
	- 보통 난이도부터 함정 재료를 슬롯에 표시
	- 가게 꾸밈은 위치 자동, 배치여부 플레이어 선택
