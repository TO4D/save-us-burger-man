# 햄버거 가게 게임 - 남은 작업 (Backlog)

> **버전**: 0.2
> **기준**: Phase 1 + Phase 2 + 주문 수락/거절 시스템 + OrderTier 리팩토링 완료 시점

## 0. 우선순위 가이드

작업은 **세 가지 축**으로 나뉩니다:

- **🎮 게임플레이**: 새 기능, 시스템 추가 (Phase 3)
- **🎨 다듬기**: 사운드, 이펙트, 에셋 (Phase 4)
- **🔧 기술 부채 / 결정 미뤘던 것들**

**추천 순서**:
1. **Phase 3 게임플레이** — 메타 루프 완성 (레벨업, 새 재료, 꾸밈)
2. **밸런스 검증** — 등급별 분포, 보상 수치 등 플레이테스트로 조정
3. **Phase 4 다듬기** — 진짜 픽셀 아트 + 사운드 + 이펙트
4. **결정 미뤘던 디테일들** — 자연스럽게 위 작업에 녹아듦

**레벨업 곡선 (초기안)**

| 1→2 | $5 |
| 2→3 | $12 |
| 3→4 | $25 |

## 6. 추천 다음 작업 (의사결정 도움)

### 6.1 만약 "메타 루프 완성을 보고 싶다"면
→ **Phase 3 (1.1 → 1.2 → 1.3 → 1.4)** 순서.
- 레벨업이 작동해야 새 재료/꾸밈 해금 검증 가능.
- 1주~10일 소요 예상.

### 6.2 만약 "재미를 더 검증하고 싶다"면
→ **임시 사운드 추가** (3.2) + **밸런스 검증** (2번).
- 사운드만 들어가도 game feel이 크게 달라짐. 무료 라이브러리 활용.
- 직접 10~20번 플레이하면서 보상/시간/거절 균형 체감.

### 6.3 만약 "보여줄 수 있는 모습을 만들고 싶다"면
→ **픽셀 아트 에셋** (3.4) 우선.
- 단, 게임 구조가 더 안 바뀔 단계에서 (Phase 3 이후) 작업 권장.
- 안 그러면 작업한 에셋이 안 맞게 될 위험.

### 6.4 만약 "출시까지 가고 싶다"면
권장 순서:
1. Phase 3 (레벨업, 새 재료, 꾸밈)
2. 밸런스 검증
3. Phase 4 (사운드, 이펙트, 픽셀 아트)
4. 첫 플레이 튜토리얼
5. 모바일 빌드 + 테스트
6. 출시

대략적 소요 (1인 개발 기준):
- Phase 3: 1~2주
- 밸런스: 2~3일 (실제 플레이 + 조정)

- 출시 준비: 1주
